# Политика конфиденциальности «Разбери фото»

Публичная страница: https://ekonchina.github.io/razberi-foto-privacy/

Репозиторий содержит страницу политики конфиденциальности и публичную иконку приложения. Исходный код приложения, APK, личные фотографии и ключи подписи сюда не входят.

## Публикация

GitHub Pages публикует `index.html` из корня ветки `main`. Файл `.nojekyll` отключает обработку Jekyll. Страница статическая: без сборки, JavaScript, внешних шрифтов и аналитики.

`icon.png` — исходная иконка приложения 512 × 512 из комплекта RuStore. Она используется в шапке страницы, как favicon и иконка для сохранения ссылки на домашний экран.

## Актуальность

- Редакция: 26 октября 2026 года.
- Проверенная версия приложения: 0.1.10+11.
- Разработчик: Кончина Екатерина Валерьевна.
- Контактный email будет добавлен до публикации приложения в RuStore.
- До подключения рекламного SDK Яндекса необходимо обновить политику по фактической конфигурации SDK и новой сборке.
- Ссылку на документ нужно добавить в карточку RuStore и внутрь приложения.

Чтобы обновить текст, измените `index.html` и дату редакции. После коммита в `main` GitHub Pages обновляет страницу автоматически.
